# CI: Gate 5, cargo parallax on every target

Seven `gate5-*` jobs in [ci.yml](../.github/workflows/ci.yml) run the examples the way an app developer does
([getting-started.md](getting-started.md)): a fresh checkout, no Cargo cache, `build/` generated by
[apply-patches.sh](../scripts/apply-patches.sh), `cargo install --locked --path crates/cli`, then `cargo parallax`.
Each passes only on the log line that proves the app ran, and checks the app's arguments after `--`
([cli.md](cli.md)) with native-view's `--no-view` (its log then says `no native view: no-view`).

They build GPUI from nothing (20 to 40 minutes each), so like the touch jobs they run on pull requests, pushes to
`main` and manual runs (`gh workflow run ci.yml --ref <branch>`), never on other branch pushes ([ci.md](ci.md)).

| Job | Runner | Runs | Passes on |
|---|---|---|---|
| `gate5-linux` | ubuntu-latest | [linux-run-check.sh](../scripts/linux-run-check.sh) `hello`, then `native-view -- --no-view`, each `cargo parallax run linux` in a private headless GNOME Shell on lavapipe | `window open`; `native-view: window open` and `no-view` |
| `gate5-windows` | windows-latest | `run windows` for hello (stopped after its line); `run windows -- --no-view --seconds 5` for native-view (it quits) | the same lines |
| `gate5-macos` | macos-latest | `build macos` for hello, `plutil -lint` its Info.plist, `codesign --verify --strict` the bundle; `run macos` for hello and `run macos -- --no-view --seconds 5` for native-view, from inside the bundle | lint and signature; the same lines |
| `gate5-ios` | macos-latest | `run ios --simulator <first iPhone>` for hello, then native-view with `-- --no-view` (simctl launch arguments) | `window open`; `no-view` |
| `gate5-web` | ubuntu-latest | `run web` for hello and native-view (`-- offset`: the URL gets `?offset`), [web-checks.mjs](../scripts/web-checks.mjs) on fresh headless Chromium (CDP) and Playwright Firefox (on Xvfb: headless Firefox finds no GL without a display), desktop and mobile, both suites; then `run web --release` with apt's binaryen and the desktop checks on it | every check (Firefox's iframe-focus row skips, [native-view-web-checks.md](native-view-web-checks.md)); no `wasm-opt not found` |
| `gate5-android` | ubuntu-latest + KVM | on android-smoke's cached API 35 emulator: `run android` for hello, then [android-smoke.sh](android-smoke.md)'s steps, then native-view with `-- --no-view` (an Intent extra) | every smoke step; `no-view` in logcat |
| `gate5-release-signing` | ubuntu-latest | a throwaway upload key (`keytool -genkey`, random masked password) in `[android.release]`; `build android --release` (`.aab`) and `--release --apk` | `apksigner verify` and `keytool -printcert -jarfile` name the key; `bundletool validate` and a universal APK built from the bundle verifies |

wasm-bindgen-cli is installed at the version in `Cargo.lock` (`cargo parallax` refuses another). The logs are each
job's artifact. What stays owed: a real iOS device (`run ios --device`) and the owner's look at macOS windows.
