# Parallax

One GPUI app, every platform. Parallax adds an Android backend, Flutter's touch, gesture and scroll feel, desktop
touch, accessibility adapters and mobile build tooling to [GPUI](https://gpui.rs), shipped with our patched GPUI fork
(`parallax-gpui*`). It ports proven code (upstream GPUI, Flutter) rather than reinventing it. Built on GPUI; not
affiliated with Zed Industries or Google.

Status: pre-alpha. Gate 1 (Android on the emulator: typing, IME, emoji, autofill, mouse) passed in 0.1.4; Phase 2
(gestures and scroll physics ported from Flutter) is in progress. Verified on emulators and simulators only so far. See [ROADMAP.md](ROADMAP.md) and [CHANGELOG.md](CHANGELOG.md). Contributors and agents: read [AGENTS.md](AGENTS.md).
