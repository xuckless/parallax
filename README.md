# Parallax

One GPUI app, every platform. Parallax adds Android, desktop touch, accessibility adapters and mobile
build tooling on top of an untouched [GPUI](https://gpui.rs). Built on GPUI; not affiliated with Zed Industries.

Status: pre-alpha, Phase 0. See [ROADMAP.md](ROADMAP.md). Contributors and agents: read [AGENTS.md](AGENTS.md).
